# 🦸‍♂️ 超級英雄學院管理系統 (Vue 3 + Vite)

這是一個基於 Vue 3 開發的英雄資訊管理系統，具備動態路由、即時搜尋、屬性排序以及詳細的技能展示功能。

## 🛠️ 技術棧
* **框架**: Vue 3 (Composition API)
* **建構工具**: Vite
* **路由**: Vue Router 4
* **樣式**: SCSS (SASS)
* **資料管理**: 非同步 Fetch JSON (public/heroes.json)

---
